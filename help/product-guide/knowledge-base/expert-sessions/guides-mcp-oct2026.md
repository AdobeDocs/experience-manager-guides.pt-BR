# MCP - Expansão do acesso a conteúdo técnico controlado

Saiba como o Protocolo de contexto de modelo (MCP) permite que experiências alimentadas por IA interajam com segurança com o AEM Guides por meio de solicitações de linguagem natural, respeitando os controles e permissões de acesso existentes do AEM. Nesta sessão, explicamos a arquitetura, a configuração, a autenticação e o modelo de segurança do MCP, demonstramos os recursos atualmente compatíveis e exploramos casos de uso práticos, limites atuais e considerações principais. Ele também aborda considerações sobre implantação para ambientes AEM as a Cloud Service e On-Prem/AMS, demonstra como clientes habilitados para MCP podem se conectar com o AEM Guides e discute onde o MCP se encaixa juntamente com os recursos mais amplos de IA do Adobe.
