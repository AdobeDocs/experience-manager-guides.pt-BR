# Atualizações de configuração para versões do Experience Manager Guides

A matriz a seguir lista a versão e as configurações recém-introduzidas ou atualizadas. Também inclui links para a documentação relacionada para obter instruções detalhadas de instalação e configuração. Use essas informações para identificar rapidamente as atualizações de configuração que podem se aplicar ao seu ambiente durante um upgrade.
